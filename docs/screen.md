# 陶晶驰串口屏接口

来自主版本 `hello_world/src/tjc_screen.c/.h` 与 `helloworld.c`。

- UART0，115200 baud；与 printf 共用串口。不要在屏幕使用期间随意插入调试文本。
- PS 发送文本命令，结尾 `FF FF FF`；波形组件使用 `addt` 透传协议，具体字节序列以驱动为准。
- 屏幕发往 PS 的按键帧：`AB + 4 字节小端无符号整数 + BA`。例如按键 1：`AB 01 00 00 00 BA`。

| 数值 | 操作 |
|---|---|
| 1 | 切换 1/3 周期显示 |
| 2 | 进入/保持测量模式 |
| 3 | 切换波形/频谱视图 |
| 4 | 请求校准，在安全边界执行，完成后恢复测量 |

| 控件名 | 内容 |
|---|---|
| `s0` | 波形/频谱，500 个显示点 |
| `t10`–`t14` | 最多 5 个分量频率，kHz |
| `t21`–`t25` | 分量幅值，mV；代码按 Vpp 使用 |
| `t3` | 重构总 Vpp，mV |
| `t4` | 由分量计算的 Vrms，mV |
| `t5` | 基波频率，kHz |
| `t31` / `t32` | 校准实测 / 目标 |

没有找到能与 8 月主版本可靠对应的 HMI 源工程；桌面 `1.HMI` 修改于 4 月 4 日，故未当作配套文件发布。控件尺寸、字体、屏幕具体型号和交互事件需在实际屏幕工程补齐，上表不能代替可烧录 HMI。
