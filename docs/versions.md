- 从原 `MyExample/ip_repo` 收集自定义 AXI-Lite IP，三版统一使用仓库内相对路径。
- FIR 版缺失的桌面 `500000D.coe` 从同工程 `ip_user_files/mem_init_files` 的保留副本恢复；没有另行设计系数替换。
- 删除 XPR 中已经不存在、且当前顶层不实例化的旧 `bram_ctrl_my.v` 引用；旧非 FIR 版也有同一失效条目。
- 禁用依赖原机器 DCP 的增量综合，保留 XPR、BD、独立 XCI、RTL、约束、COE 和应用源码。
- 不收入 BSP、工具缓存、工作区日志、调试配置、BOOT.bin/XSA/ELF 和实现输出；未将未核验 HMI、教材、供应商整套资料或其他题目混入。
- 来源清单 `source-manifest.json` 记录本地源工程相对路径、原修改时间和原文件 SHA-256；它是导入来源清单，路径修复后的发布文件可能有不同 SHA-256。

此整理没有改写旧 Git 历史，因此旧版本的缓存仍可在历史中找到。主分支清理不等同于缩减历史下载体积。
