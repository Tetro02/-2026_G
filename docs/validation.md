## 使用边界

- 主版本尚无本轮板级采样、测量精度、校准或串口屏联调记录。
- 不包含模拟前端原理图、PCB、BOM、完整 HMI、正式设计报告或实验照片，不能当作整机即插即用交付。
- 频率约束、幅度比例、DDC 增益和校准系数来自原源码，依赖原硬件。零相位重构不保留多音信号的相对相位。
- 原 XDC 含 `UART_0_2_rxd` 的遗留约束，但主版本顶层仅引出该口 TX；主版本发布副本去除了无对应端口的这一条约束，不新增接线。
- 原工程虽有旧 bitstream / ELF / XSA，但此次没有将其作为已验证固件分发。
- 历史中的第三方生成物保留原声明，主分支清理没有改写历史。
